Снаряжение

Категория: Снаряжение

Доступно: 6 снаряжении

Обновлено: Актуально с последним обновлением.

Снаряжения — оборудование реагентов для оказания помощи во время прохождения испытаний. Каждый тип снаряжения имеет свои уникальные улучшения и тактики использования.

Снаряжения или Риги (ориг. Rigs) — несколько типов снаряжения для реагента, которые можно активировать и улучшить у инженера Корнелиуса Ноукса в комнате отдыха. Покупка и дальнейшее улучшение снаряжения покупается за ваучеры, которые реагент получает в ходе повышения уровня. Реагент может купить все типы снаряжения, но на испытании он может использовать только одно выбранное. Изменить приобретённое снаряжение реагент может в любое время вне испытания.

Без улучшения «Подготовка» снаряжению требуется время в начале испытания, чтобы прийти в готовность. После использования снаряжения на испытании устройству требуется время на его восстановление. Однако с помощью одноразовой зарядки снаряжения, которые находятся в областях испытаний, реагент сможет снова активировать устройство. У каждого типа снаряжения своё время для восстановления после использования.

ВНИМАНИЕ! После каждого использования вашему снаряжению требуется время для перезарядки перед повторным использованием.
